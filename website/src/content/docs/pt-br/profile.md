Alguns formulários de newsletter pedem mais que o e-mail: um nome, um país, às vezes a empresa ou o cargo. A aba **Perfil** guarda os dados que o mailWarmer usa para preencher esses campos extras.

## Uma identidade pronta

Na primeira instalação o mailWarmer gera um perfil fictício e crível, para as inscrições por formulário funcionarem de cara. Você não precisa mexer nesta aba. Mude qualquer campo quando quiser.

Os campos são: nome, sobrenome, nome completo, idade, data de nascimento (AAAA-MM-DD), gênero, país, estado / região, cidade, CEP, telefone, empresa, cargo e site.

## Botões

- **Preencher vazios** — preenche só os campos vazios com valores gerados. O que você digitou fica.
- **Gerar tudo de novo** — troca o perfil inteiro por uma nova identidade fictícia. Ele pede confirmação antes.
- **Salvar perfil** — no fim do formulário. Clique depois de editar; mudanças não salvas não são usadas.

## Quando ele é usado

Só nas newsletters de formulário (etiqueta <span class="pill blue">formulário</span>), e só nos campos que o formulário realmente pede. As inscrições do Substack só precisam do e-mail.

## Privacidade

O perfil fica no armazenamento local da extensão, no seu navegador. Ele só é digitado nos formulários de inscrição das newsletters que você roda e nunca é enviado para nós.
